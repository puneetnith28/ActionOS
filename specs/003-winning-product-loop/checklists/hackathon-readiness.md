# Hackathon Readiness Checklist: Winning Product Loop

**Feature**: [spec.md](../spec.md)

## Stage 1 — Eligibility and Access

- [ ] Participant confirms sanctions/conflict eligibility.
- [ ] Judge repository access is verified from a clean account.
- [ ] Public deployed app is reachable without paid credentials.
- [ ] Final category is exactly Taskmaster.
- [ ] New-project provenance and dependency licenses remain documented.

## 40% — Innovation and Utility

- [ ] Four visible examples complete end to end during one session.
- [ ] Review is editable and understandable without technical details.
- [ ] The user can leave and recover the case on another device.
- [ ] Weak evidence is rejected visibly before accepted proof.
- [ ] Claims distinguish demo protocol from real-company capability.

## 30% — Architecture

- [ ] Gemini 3.5+ and Genkit usage is essential, visible and measured.
- [ ] Cloud Run, Firestore and Cloud Tasks evidence is correlated to the demo case.
- [ ] Approval, policy, model, adapters and verifier remain separate boundaries.
- [ ] Retry, restart, duplicate delivery and stale approval tests pass.
- [ ] False-DONE adversarial email tests pass before email can be enabled.

## 30% — Demo and Production Readiness

- [ ] Intake returns a durable case promptly and resumes after refresh.
- [ ] Judge Evidence Console shows persisted redacted records.
- [ ] Primary production path passes with one worker and zero retries.
- [ ] One continuous video is at most four minutes and English-accessible.
- [ ] Video shows real model call, autonomous action, rejection, retry/dedupe, proof and Cloud evidence.
- [ ] Architecture diagram and reproducible deployment match the final revision.

## Final Submission

- [ ] Public YouTube/Vimeo URL is in Devpost copy.
- [ ] App URL, repository URL, category, technologies, limitations and learnings are complete.
- [ ] No placeholder, synthetic-user claim or unsupported integration claim remains.
- [ ] Submission is completed before 2026-08-31 17:00 PT.
- [ ] Deployed app remains available through judging.
